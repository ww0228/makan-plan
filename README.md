# 🍽️ MakanPlan

**MakanPlan** is a meal planner that helps users, especially students and low-income households to plan affordable, nutritious meals and reduce food waste.  

The system supports **SDG 2: Zero Hunger** by:
- Making food inventory visible  
- Linking meals to what is already on hand  
- Showing costs while planning 

## 🌟 Main Features

### 🧺 Inventory
- Record item **name**, **quantity**, **unit**, **expiry date**, and **total cost**  
- Highlights items that **expire soon** to help reduce waste  

### 🍛 Meal Planner
- Automatically creates an **active Monday–Sunday plan**  
- Users can **add**, **edit**, and **delete** meals  
- **Meal cost** is calculated from **inventory cost-per-unit**  
- Displays a **weekly total** for easy budgeting  

### 📖 Recipe Book
- Store **recipe titles**, **ingredients**, and **instructions**  

### 🥗 Dietary Preferences & BMI
- Save **dietary needs** (e.g., **halal**, **vegetarian**)  
- View basic **BMI feedback** for health awareness  

### 👤 Login / Profile
- Keeps data **per user** for **personalised plans and inventories**
